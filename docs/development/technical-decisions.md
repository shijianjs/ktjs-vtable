# 技术决策

生成器（`scripts/generate-api.py` + `scripts/ktjs_emitter.py`）把上游 `.d.ts` 落成 Kotlin external 声明时做的
判断，按「上游写法 → 处理方式 → 理由」记录。改生成器前先看这一页，改完补一条。

## 范围与包划分

- **core 与 editors 合成一个 Kotlin 包 `io.github.shijianjs.ktjs.vtable`**：两个包版本一致、总是一起发版，
  拆开只会多出一个 Maven 版本；`editors` 的 `IEditor` 被 core 的列定义引用，同包不需要跨模块 `api` 依赖。
- **只做 MIT 包**：`export` / `search` / `plugins` / `gantt` / `sheet` / `calendar` 待完成；
  `react` / `vue` / `openinula` 绑定明确不做（Kotlin/JS 用不上框架组件）。

## 模块说明符（`@file:JsModule`）

| 上游 | 处理 | 理由 |
| --- | --- | --- |
| `@visactor/vtable` 无 `exports` map | `@visactor/vtable/es/<path>.js` | 声明是 `.d.ts`，运行时是 `.js`；Kotlin/JS 产出的 bundle 按 strict ESM 解析，省略扩展名 webpack 直接报 `fully specified` |
| `@visactor/vtable-editors` 只有 `"."` | 统一 `@visactor/vtable-editors` | `exports` 拒绝深导入；包很小，从根导入不影响摇树 |

## 命名

- **公开别名优先拿短名**：上游 `ListTableAll` 与基类 `ListTable` 同名冲突时，别名拿 `ListTable`、基类退成
  `ListTableBase`（调用方几乎只用别名）。
- **改名必须带 `@JsName`**：Kotlin 名与 JS 导出名不同时（上面这种别名、`_` 成员、签名冲突的重命名），
  一律 `@JsName("上游名")`，否则 webpack 报 `export 'X' was not found`。
- **`_` / `__` 成员**：Kotlin 保留字，暴露为 `typedUnderscore<N>` 并用 `@JsName` 映射。
- **签名冲突的继承成员**：external 成员不能 `open`，所以基类已有的同签名成员直接跳过；不同签名的改名成
  `typed<Name>`（如 `getCellRawRecord` → `typedGetCellRawRecord`）。

## 类型形状

- **联合类型**：一个不透明 `external interface` + 每支一个同名工厂，全包去重。上游 `Either<A, B>` 直接
  解析成联合，不额外造 `Either` 层次。
- **字符串字面量**：`sealed external interface` + `X(String)` 工厂 + `Xs` 常量对象（如
  `StandardOrAdaptiveOrAutoWidths.adaptive`）。不使用 `enum class`，因为运行时值必须是字符串。
- **交叉类型**：单 ref 交叉 → `external interface X : Base`；多 ref 交叉 → 多父接口。
- **`Function` 无类型参数** → `Function<*>`；`any` / `unknown` → `JsAny`，KDoc 注明上游原文。
- **空扩展接口的 `X[keyof X]` 索引分支丢弃**：保留它会让整个联合塌成 `JsAny`，丢掉真正有用的分支。
- **getter/setter 对** 合并成一个 `var`（新增 member kind `setter`）。
- **`const version = "1.26.8"`** 字面量推断成 `String`，不丢声明。
- **`export { A, B as C }`（没有 `from`）**：`index.d.ts` 靠它导出 42 个名字，按本地导出解析；
  `import * as TYPES` 展开成该模块全部导出。

## 类与成员

- **`open external class`**：上游会继承自己的类，external 类默认 final，必须 `open`。
- **`implements` 折进类体**：Kotlin external class 不能实现接口，接口成员直接声明在类上（与上游类体形状一致）。
- **同名同签名跳过、不同签名 `@JsName` 重命名**：见「命名」。
- **`Any` 自带的成员**（`toString` 等）改名 `typed<Name>`，避免与 `Any` 冲突。

## 生成的可重跑性

- 生成前删除输出目录下所有 `*.kt`；**手写文件必须放在别的目录**（本项目是 `dsl/` 子包）。
- 每个文件头写 `// Generated by scripts/generate-api.py from @visactor/vtable <version>.`，便于识别与清理。
- 生成器 CLI 的 `--types` / `--editors-types` 是显式路径，既能指向 `node_modules`，也能指向解包的 tarball；
  CI 用 `node_modules`，本地排查可以指向临时目录。

## 手写 DSL 的边界

- DSL 只覆盖日常构造：选项构造器、列/行助手、主题取用。其余字段始终可以回到生成的类型上赋值。
- `row(...)` 是唯一动态构造对象的地方：记录是以列名为键的开放字典，Kotlin 没有对应的索引签名对象字面量，
  用 `js("{}")` + `dynamic` 写入，返回 `JsAny`。`unsafeJso` 在这里不可用——它只降级静态已知属性名，
  对 `this[key] = value` 会编译出普通对象上不存在的 `set(...)` 调用（2026-11 实测 `e.set is not a function`）。
- 编辑器注册、主题注册直接调用生成的 `editor()` / `theme()`，不另造注册表。
