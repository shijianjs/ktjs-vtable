<ktjs-features section-title="What the wrapper gives you" tinted>

<ktjs-feature icon="lucide:table-2" title="Canvas tables, Kotlin types">`ListTable` and `PivotTable` with columns, records, events and themes typed from `@visactor/vtable`'s own `.d.ts` files.</ktjs-feature>

<ktjs-feature icon="lucide:edit-3" title="Editors included">`@visactor/vtable-editors` is wrapped in the same module, so cell editing needs no second dependency.</ktjs-feature>

<ktjs-feature icon="lucide:shield-check" title="Checked, not dynamic">Every member the upstream package declares has a Kotlin type; unions and string literals keep their own factories and constant objects.</ktjs-feature>

<ktjs-feature icon="lucide:wrench" title="A DSL for the common case">One-liners for columns and rows, so a working table is five lines instead of a hand-built options object.</ktjs-feature>

<ktjs-feature icon="lucide:languages" title="Docs and demo in two languages">The documentation and the demo page both switch between English and Chinese.</ktjs-feature>

<ktjs-feature icon="lucide:list-checks" title="Progress you can read">Coverage per upstream package is tracked in the repository, with what is done, what is pending and what is out of scope.</ktjs-feature>

</ktjs-features>
