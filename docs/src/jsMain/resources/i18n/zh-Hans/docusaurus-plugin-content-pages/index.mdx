<ktjs-features section-title="封装给了你什么" tinted>

<ktjs-feature icon="lucide:table-2" title="Canvas 表格，Kotlin 类型">`ListTable` 与 `PivotTable` 的列、记录、事件、主题都按 `@visactor/vtable` 自己的 `.d.ts` 生成。</ktjs-feature>

<ktjs-feature icon="lucide:edit-3" title="编辑器也在">`@visactor/vtable-editors` 在同一个模块里，单元格编辑不需要第二个依赖。</ktjs-feature>

<ktjs-feature icon="lucide:shield-check" title="检查过，而不是 dynamic">上游声明的每个成员都有 Kotlin 类型；联合类型与字符串字面量保留各自的工厂和常量对象。</ktjs-feature>

<ktjs-feature icon="lucide:wrench" title="常见用法有 DSL">列和行都是一行代码，一张能用的表是五行，而不是手搭一个选项对象。</ktjs-feature>

<ktjs-feature icon="lucide:languages" title="文档与演示都双语">文档站和演示页都能在中文与英文之间切换。</ktjs-feature>

<ktjs-feature icon="lucide:list-checks" title="进度可查">每个上游包的覆盖状态都记在仓库里：已完成、待完成、明确不做。</ktjs-feature>

</ktjs-features>
